TRAIN ONE COMPONENT FIRST
04 / The identification problem

两个 agent 完全一致，也可能一起打错分。

强模型 A 可以提供低成本监督，但它的可靠性需要用独立人工标注校准。

Counterexample · 构造数据 / 满分 10 分
答案人工参照L+L−
答案一255
答案二555
答案三855
0 平均 gap
2.0 平均分相对人工的 MAE

常数评分拿到了完美的一致性奖励，却丢失了区分答案质量的能力。

1有人工评分：优先作为外部参照

保留双评分者信息；对争议样本复核。人工评分本身也可能有不确定性。

2使用强模型 A：定位为有噪声的老师

A 使用固定评分标准，先评估其人工一致性，再生成训练监督；不要让它随候选 rubric 一起漂移。

3没有可靠参照：限制可得出的结论

可以验证协议一致性改善；仅凭 gap 收敛，无法判断评分是否更正确。

建议将 A 放入消融实验：gap-only / 均值对齐 A / gap + 均值对齐 A，最终都用未参与优化的人工标注评估。

要研究的是“更稳定且有效的评分”，而不是把某个强模型的输出直接定义为真值。

LITERATURE CHECK · 2026-10-29
06 / Paper 01 · Reflect-and-Revise

让模型从错分案例中修订评分规则。

优化对象是 rubric 文本。通过“评分 → 找错 → 反思 → 改写”的循环，使模型更接近人工评分。

CoNLL 2026不更新模型权重需要人工分数
  1. 用当前 rubric 给训练作文评分

    每个设置使用 100 篇带人工分数的作文，保留预测分数与评分理由。

  2. 从错分案例提取规则缺口

    按人工分数分层抽取不一致案例；结合原文、分数差异与理由反思。

  3. 生成并筛选候选 rubric

    把模糊描述改成条件、阈值、封顶规则等；按训练集 QWK 保留前 3 个候选。

  4. 迭代 5 轮，再在留出集评估

    测试标签不参与修改；检验改写是否能泛化到新的作文。

对你的方案：必须比较的强基线

先检验加入 L+ / L− 分歧后，能否比“仅用人工或 A 的误差反馈修订 rubric”更有效。固定标签与调用预算，才能识别 gap 的额外价值。

收益并非普遍成立：TOEFL11 上 GPT-5 mini 的 QWK 为 0.526 → 0.506。ASAP、ASAP 2.0 的实验各只选一个题目，跨题结论有限。

关键等式：分别追 A，已隐含 gap 惩罚

(S+ − tA)² + (S− − tA)²
= 2(m − tA)² + ½(S+ − S−)²

其中 m = (S+ + S−) / 2。对两路分别使用平方误差时，“A-only”本身就会压缩 gap。

因此，消融要明确拆开两个作用

均值对齐 A：仅优化 (m − tA)²。
Gap-only：仅优化 (S+ − S−)²。
组合：均值对齐 + 可独立调权的 gap。
用留出人工分数验收；A 的错误可能被两条路径共同继承。

10 / Experimental design

先回答三个问题，再决定 RL 是否值得投入。

第一阶段固定同一个基础模型，隔离“评分协议”的影响；第二阶段再测试跨模型迁移。

H₁

路径分歧是否超出随机波动？

比较 L+ / L− 的差距与同协议重复评分的差距。控制输入、采样设置和输出格式。

H₂

分歧是否包含有用的误差信息？

分析 gap 与人工评分误差的关系；复核高 gap 样本是否集中在部分分、遗漏与隐含表达。

H₃

利用分歧能否改进未见样本？

优化后的 rubric 同时降低 gap 与人工评分误差，并保留对答案质量的区分能力。

Controls · 必须保持的实验条件
  1. 语义等价：相同考点与权重；明确部分分、遗漏和重复扣分规则。
  2. 独立评分：两路互不见对方分数；逐项返回证据，程序计算总分。
  3. 严格划分：先做题内答案留出，再做按题目留出；测试标签不进入修改流程。
  4. 正确归因：增加等长度 rubric 与同协议重复评分对照；报告逐题结果和置信区间。

阶段 1 · 发现信号

普通电脑 + 模型 API + 已标注数据

同模型双协议，多次重复；估计 gap 是否超过随机波动，并分析与人工误差的关系。

阶段 2 · 优化基线

提示修改 + 独立测试 + 人工复核

复现误差反馈式 rubric 修改。建议抽取 100–200 份争议或高 gap 答案复核；这是拟议规模，可随预算调整。

阶段 3 · 有条件投入 RL

4B / 8B rubric 生成器 + 固定评分器

GenRubric 报告 2×H800，可作为参考配置；不代表本项目的最低需求或完整 GPU 时预算。多次评分推理需另计。[2]

候选评估的放大效应：8 个 rubric × 16 份答案 × 2 个方向 = 256 次评分，尚未计入重复采样。

是否投入 RL，由前两阶段的证据决定。没有观察到有效信号时，不以增加训练规模替代问题诊断。

ESTIMATE, NOT A QUOTE
13 / Success & failure criteria

成功需要三个结果同时成立。

gap 缩小、人工误差下降，以及改进在未见样本中保持。当前所有实验结果均为待测。

Gate 01

没有超出随机波动的路径差距

先修正协议操纵与测量设计；暂不进入 RL。

Gate 02

gap 下降，但人工误差不变或上升

不能支持“评分更准确”；检查奖励利用、分数塌缩与 A 的共同偏差。

Gate 03

组合信号在留出集优于强基线

再测试跨题与跨模型迁移，判断收益来自可解释的 rubric 澄清，还是特定模型的适配。

只有一致性改善时，研究结论应限定为“协议稳定性”；准确性与公平性需要各自独立的证据。

PREDEFINE THE CLAIM BEFORE TRAINING
14 / Discussion

能否把评分分歧，
转化成澄清规则
的训练信号？

From disagreement to explicit criteria.

潜在贡献是识别一种可操作的歧义信号，
并验证它能否产生更稳定、更准确的评分。

建议下一步：ASAP-SAS 上先做 500 份答案的协议实验；若信号成立，进入 rubric 提示优化与消融，之后再评估 RL。

01先聚焦哪一类评分？

建议短答题与部分分规则起步。确认题目是否可拆成等价的加分与减分规则。

02如何定义可信参照？

现有人工分数作为外部评估；A 提供训练监督时，明确校准、冻结与抽样复核方案。

03何种证据值得投入 RL？

gap 超出随机波动，能反映评分问题，并且以 gap 驱动的 rubric 修改已在留出集显示收益。

第一阶段的目标：验证信号是否存在，以及是否有用。
