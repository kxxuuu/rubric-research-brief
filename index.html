02 / The intuition

分歧可能来自评分规则中未写明的判断。

同一题目、同一答案、同一模型；只改变评分方式。下面用一个构造示例说明直觉。

7/ 10

L− 减分式10 → S

两种评分方式都能给出解释，但采用了不同的默认假设。

待验证的假设
明确得分点、部分分与遗漏规则后，两条评分路径的差距会缩小。

加分、减分必须是同一评分政策的两种表达；L− 与 L+ 不自动构成分数的上下界。

LOCALIZE, THEN REWRITE
04 / The identification problem

两个 agent 完全一致，也可能一起打错分。

强模型 A 可以提供低成本监督，但它的可靠性需要用独立人工标注校准。

Counterexample · 构造数据 / 满分 10 分
答案人工参照L+L−
答案一255
答案二555
答案三855
0 平均 gap
2.0 平均分相对人工的 MAE

常数评分拿到了完美的一致性奖励，却丢失了区分答案质量的能力。

1有人工评分：优先作为外部参照

保留双评分者信息；对争议样本复核。人工评分本身也可能有不确定性。

2使用强模型 A：定位为有噪声的老师

A 使用固定评分标准，先评估其人工一致性，再生成训练监督；不要让它随候选 rubric 一起漂移。

3没有可靠参照：限制可得出的结论

可以验证协议一致性改善；仅凭 gap 收敛，无法判断评分是否更正确。

建议将 A 放入消融实验：gap-only / 均值对齐 A / gap + 均值对齐 A，最终都用未参与优化的人工标注评估。

要研究的是“更稳定且有效的评分”，而不是把某个强模型的输出直接定义为真值。

LITERATURE CHECK · 2026-11-05
06 / Paper 01 · Reflect-and-Revise

让模型从错分案例中修订评分规则。

优化对象是 rubric 文本。通过“评分 → 找错 → 反思 → 改写”的循环，使模型更接近人工评分。

CoNLL 2026不更新模型权重需要人工分数
  1. 用当前 rubric 给训练作文评分

    每个设置使用 100 篇带人工分数的作文，保留预测分数与评分理由。

  2. 从错分案例提取规则缺口

    按人工分数分层抽取不一致案例；结合原文、分数差异与理由反思。

  3. 生成并筛选候选 rubric

    把模糊描述改成条件、阈值、封顶规则等；按训练集 QWK 保留前 3 个候选。

  4. 迭代 5 轮，再在留出集评估

    测试标签不参与修改；检验改写是否能泛化到新的作文。

作者结果 · ASAP / GPT-5 mini / QWK ↑
评分设置测试 QWK
人工编写的原始 rubric0.119
AutoCalibrate 基线0.487
Reflect-and-Revise0.522

+0.403 是相对原始 rubric 的最佳组合增益；同一设置相对 AutoCalibrate 的增益为 +0.035。QWK 衡量有序评分一致性，并加重较大分差的惩罚。

对你的方案：必须比较的强基线

先检验加入 L+ / L− 分歧后，能否比“仅用人工或 A 的误差反馈修订 rubric”更有效。固定标签与调用预算，才能识别 gap 的额外价值。

收益并非普遍成立：TOEFL11 上 GPT-5 mini 的 QWK 为 0.526 → 0.506。ASAP、ASAP 2.0 的实验各只选一个题目，跨题结论有限。

LEARN THE JUDGE
09 / Paper 04 · Agreement Without Alignment

分歧驱动的澄清提高了共识，但没有更接近人工。

Han & Kim（arXiv 2610.13303，2026-10-09）。与你的想法最接近：用评分分歧定位并改写 rubric 中的歧义条款；人工标签只用于评估。

2026 预印本不训练、不迭代人工标签仅用于评估
  1. 把 rubric 拆成原子子条款

    由编辑模型拆分；三个数据集共 75 条子条款。

  2. 按 judge 分歧率挑选条款

    5 个 judge（3 家厂商）逐条判 pass / fail / NA；在开发集上计算 10 个 judge 对的分歧率，最多选 min(5, ⌊n/2⌋) 条。

  3. 针对分歧改写，并设随机对照

    给出分歧样本与 judge 理由，每条只改写一次，不许引入新考点；对照组改写同样数量的随机条款。

  4. 在留出集上同时测共识与人工一致性

    共识用 Krippendorff α，人工一致性用 Kendall τ；预先设定效应阈值。

对你的方案：它的负结果正是你的动机

只追求共识不会自动更准。你的区别：① 分歧来自同一模型的加 / 减分执行，而非不同模型的能力差异；② 有 A 锚定项处理偏差；③ 学生短答与部分分场景，且迭代优化。

必须引用，并在消融中加入“跨模型分歧”组，直接比较两种分歧信号。

(S+ − tA)² + (S− − tA)²
= 2(m − tA)² + ½(S+ − S−)²

12 / Discriminating experiment

gap 变小，是不是 rubric 真的变好了？

评分误差可粗分为偏差（规则定错）与歧义（规则没写清）。gap 主要测歧义；两路同侧偏离时 gap 测不到偏差。用人工分数当裁判，区分三种可能。

a同侧也行：只要一起走向 A 就更准

修正的是偏差；但只对齐 A 也能做到，gap 没有独立作用。

b不论方向：gap 变小就更好

修正的是歧义；只在歧义是主要误差来源的题目上成立。

cgap 收敛与精准无关

误差主要来自偏差，或 gap 未超出随机波动。

预期三者因题而异。若成立，gap 项负责歧义、A 项负责偏差，两项互补，类似偏差-方差分解。
分析 · rubric 变体回归（不需训练）

人工误差 ~ β₁·gap + β₂·|m − tA| + 题目固定效应

A 距离 ↓A 距离 ↑
gap ↓预期最好关键格：人工误差仍下降 → gap 独立有用
gap ↑只对齐 A 的效果预期最差
  1. β₁ 控制 A 距离后仍显著 → 支持 (b)
  2. 只有 β₂ 显著 → 支持 (a)，gap 是多余的
  3. 两者都不显著 → 支持 (c)，或 A 本身不可靠
  4. 按 tA 是否落在 [S+, S−] 分组：若只有区间内样本的 gap 与人工误差相关，即支持“gap 只管歧义”。

A 冻结且不读 R，不存在“A 走向 L”。变体包括改写措辞、删减部分分规则、加入边界说明、调整权重，需通过语义等价检查。

AMBIGUITY VS. BIAS
12 / Discriminating experiment V2 修订

哪种分歧，真的指向 rubric 的缺陷？

V1 把 gap 与 A 距离对比。V2 把加减分分歧与其他无标签信号对比，并修正两个统计问题：机械相关与答案难度混淆。

a加减分分歧有额外信息

控制其他四种信号后仍能预测人工误差：它捕捉到“默认规则未写明”这类特定歧义。

b任何扰动都差不多

解释力不高于同义改写或顺序打乱：它只是通用的不稳定性度量，加减分设计没有特殊价值。

c都不预测人工误差

分歧反映的是模型自身的不稳定，与 rubric 质量无关；与 Han & Kim 的结论一致。

三种结果都可以报告。只有 (a) 支持继续做分歧定位改写；(b) 说明应改用更便宜的扰动；(c) 则到此为止。

Where the gap comes from

1“未规定”不是来源

“未规定”只占条目判定的 1%–7%，原版最高。两种协议同等计分后，gap 仍是 0.876 / 0.616 / 0.443。

2来源是相反的判定

加分协议判满足、扣分协议判不满足的条目，占 16.2% → 8.3% → 4.9%。

3扣分协议反而更严

模糊版下扣分协议平均低 0.44 分。模型没有遵守“有疑问就不扣”。

4条目层面的指标更稳

两种协议多数判定不同的条目占 24.3% → 16.3% → 9.7%；剔除 E06.Q06 后是 22.5% → 19.7% → 11.2%。
